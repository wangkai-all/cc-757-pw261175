# 分支关系工作台（本地、虚构数据）

一个从零搭建的**本地**树形关系分析工作台：导入虚构样品的离散特征矩阵与特征改变代价，
在给定代价模型下寻找总变化代价较小的树形，并**明确标注仍然存在的等价结构**。

> 所有内置样例都是虚构的教学数据。这里只回答“这组离散特征在这棵树上要付多少代价”，
> **不推断真实生物亲缘关系**，也不声称任何祖先状态是真实形态。

## 运行

```bash
npm install
npm run build     # 构建前端到 web/dist
npm start         # 启动本地服务，默认 http://127.0.0.1:4173
```

开发模式（前端热更新，API 仍在 4173）：

```bash
npm run dev       # Vite 在 5174，/api 代理到 4173
```

测试：

```bash
npm test                         # node --test：模型、求解器、API
node scripts/browser-check.mjs   # 可选：用 Playwright 打开页面并截图到 /tmp/shots
```

一切都在本机完成，数据与结果不发送到任何外部服务。

## 使用

1. 左侧选择内置虚构样例，或“导入 JSON”/“新建空白数据”。
2. 在“特征矩阵”里点任意一格改状态；缺失写成 `未观测`（底层是 `null`）。
3. 在“特征与代价”里为每个特征单独保存转移代价：无序特征每对状态一份**对称**代价，
   有序特征每个**方向**单独定价，可以不对称。
4. 在“锁定分支”里选择若干样品，要求它们构成一个**共同分支**。
5. 右上选择搜索方式后按“求解”。
6. 右栏查看：结果（总代价、按特征拆分、当前树的枝条明细）、候选树（等代价结构）、
   诊断（缺失、数据不足、锁定冲突、局部搜索未证明最优等）、核对与重采样。

## 语义要点

### 缺失不是类别

未观测格存为 `null`，在定价时是**通配**：它不增加任何状态，也不产生任何枝条代价，
更不会在树上被标成某个状态。校验器会把任何“没声明的状态字符串”单独报错，
不会把它当成新的类别。

### 有序 / 无序与代价存储

- 无序特征：转移代价按无序对 `{a, b}` 保存，必须对称；不对称时校验器会报错。
- 有序特征：按有向转移 `a>b` 保存，两个方向可以不同。
- 每个特征各自保存自己的代价表，互不影响。

### 锁定进入搜索

锁定约束在求解**内部**生效：

- 精确搜索在划分根节点左右子集时，要求每个锁定整体落在同一侧；
- 局部搜索的邻域移动会拒绝破坏锁定的候选，并以锁定可行的树为起点；
- 互不相容的锁定（例如同时要求 `{A,B}` 与 `{A,C}` 为共同分支，二者相交但不互相包含）
  在校验阶段就被拒绝，并指名是哪两个锁定、共享与各自独有哪个样品。

### 精确 vs 局部，诚实标注

- **精确搜索**：对样品子集做联合状态向量的动态规划，在可枚举规模内穷尽全部拓扑，
  结果标注为“代价由精确搜索证明最优”，并列出全部等代价的有根树形。
- **局部搜索**（NNI + 叶重挂）：只返回“这次搜索找到的最好树”。同时给出一个
  **独立于搜索过程**的 MST 下界（按特征求状态间最短路、再求最小生成树）。
  只有当下界与代价相等时才说“在该松弛下已证明最优”；否则明确显示差额，
  绝不把局部最好称为全局最优。

### 等价结构

相等总代价的有根树形会全部列出（精确搜索下完整，除非明确提示被截断），
并按**未根化分割**分组：只差根位置、未根化结构相同的树形归到同一组，
避免把根的位置当成不同的分支关系。

### 重采样以特征为单位

重采样抽取的是**整列特征**（不是逐格），且锁定约束在每个重复里保持不变。
可只对当前树重新计价，或对每个重复重新求解。结果只反映特征抽样的波动，
**不是置信区间**，也不代表真实亲缘关系。

## 内置样例

| 样例 | 用途 |
| --- | --- |
| 虚构类群·特征矩阵 A | 6 样品、3 特征、1 个锁定、1 个缺失格；最优代价 8，多个等代价结构 |
| 互斥锁定样例 | 两个相交但不包含的锁定，求解器必须报冲突并说明 |
| 同代价多解演示 | 10 个有根树形同为最优，归为 2 个未根化结构 |
| 数据不足演示 | 所有特征恒定，任何树代价都为 0，用于核对“数据不足以区分分支” |

## 目录

```
shared/          校验、代价模型、锁定冲突检查（前后端共用）
server/solver/   定价、精确 DP、局部搜索、下界、独立枚举核对、重采样
server/          本地 API、后台 worker 任务
web/src/         React 界面（矩阵、代价、锁定、树视图、诊断、核对）
data/            内置虚构样例
test/            模型 / 求解器 / API 测试
scripts/         本地开发与无头浏览器验证脚本
```

无头浏览器验证依赖本机 Chromium 所需的库与字体；若环境缺少这些依赖，
`scripts/browser-check.mjs` 可能无法启动，但 `npm test` 与 `npm start` 不受影响。
